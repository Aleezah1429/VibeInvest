# Plan — Final Verdict & Share

## Goal
The closing card: the CVO's portrait, the verdict in huge text, the one-line verdict_line ("Contradictions resolved. The numbers make sense. Rizz level: High."), and three share affordances — **Export Investor Report (PDF)**, **LinkedIn**, **WhatsApp**. This is what the founder screenshots and posts.

**Phase:** 0 (hackathon MVP).

## User stories
- As a founder, I see the CVO's "ruling" in one screen — verdict label, justification line, and what to do next.
- As a founder, I can one-tap export a PDF of the full report I can attach to a pitch email or DM to an angel.
- As a founder, I can share the Aura Card to LinkedIn (caption pre-filled) or WhatsApp (deep link with text).
- As a demo presenter, the export PDF looks credible — not a hacky screenshot.
- As Lane B, the share affordances are all client-side (no server round-trips).

## Architecture sketch

```
components/
  final-verdict/
    VerdictCard.tsx               CVO portrait, verdict label, verdict_line, share buttons
    ShareMenu.tsx                 LinkedIn / WhatsApp / Copy Link affordances
    ExportReportButton.tsx        Triggers PDF generation via lib/investor-report.ts

lib/
  share-card.ts                   Aura Card → 1080×1080 PNG via jspdf
  investor-report.ts              Full report → multi-page PDF via jspdf
  share-targets.ts                Constructs LinkedIn / WhatsApp / Twitter share URLs

public/share-card/                Template assets — background, brand mark, font
```

## Investor Report PDF structure

| Page | Content |
| --- | --- |
| 1 | Cover: VibeInvest logo, idea text, Aura Score, verdict |
| 2 | Skeptic section: competitors, saturation, red flags |
| 3 | Munshi section: unit economics, burn, year-1 revenue |
| 4 | Hype section: taglines, brand vibe, pitch deck fixes |
| 5 | CVO section: dimensional scores, top 3 fixes, next steps |
| Footer | "Generated by VibeInvest on YYYY-MM-DD" + URL |

Generated client-side using `jspdf` — already in the dep list. No new backend route needed.

## Share targets

| Target | Mechanism |
| --- | --- |
| LinkedIn | `https://www.linkedin.com/sharing/share-offsite/?url=<page-url>` opened in new tab |
| WhatsApp | `https://wa.me/?text=<urlencoded>` with the verdict_line + a link to the run URL |
| Copy link | `navigator.clipboard.writeText(window.location.href)` |

In Phase 0, the "run URL" is ephemeral — refreshing it loses the report. That's fine for demo. Phase 1 (Firestore persistence) makes URLs durable.

## Decisions
- **All share is client-side.** No backend route in Phase 0.
- **PDF is generated on demand, not pre-rendered.** Button click → generate → trigger download.
- **The Aura Card PNG is separate from the Investor Report PDF.** The PNG is the social asset; the PDF is the formal report. Both come from the same `final_report`.
- **Verdict-line styling matches the verdict color.** Reuses `VERDICT_THEME` from the aura-audit feature.
- **CVO portrait is a single static asset.** No procedural avatar generation in Phase 0.

## Out of scope (Phase 0)
- Email-the-report (Phase 1 — needs SMTP)
- Twitter / X share button (Phase 1)
- Custom watermark per user (Phase 2)
- "Send to angel" with pre-filled recipient list (Phase 3)
- PDF customization (logo, font choices) (Phase 1)
